Todoist MCP

Use Todoist from your AI assistant

A hosted Model Context Protocol server for Todoist. Works with Claude, ChatGPT, Gemini CLI, Cursor, VS Code and any other client that supports remote MCP servers.

Connect Todoist

How it works

  1. Sign in to Todoist and approve access.
  2. You get a personal server URL.
  3. Add that URL to your assistant as a custom connector or MCP server.

What your assistant can do

Read, create, update and complete tasks; manage projects, sections and labels; read and add comments.
