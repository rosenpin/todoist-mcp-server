Claude

In claude.ai or Claude Desktop, open Settings → Connectors → Add custom connector, name it “Todoist”, paste the URL, then choose Connect and sign in with Todoist.

For Claude Code, run this, then sign in from /mcp inside Claude Code:

claude mcp add --transport http todoist {{ORIGIN}}/mcp
ChatGPT

Enable Developer mode under Settings → Apps & Connectors → Advanced, then choose Create, paste the URL, set authentication to OAuth and sign in with Todoist.

Gemini
  1. Open Connectors and click + Custom.
  2. Enter {{ORIGIN}}/mcp as the MCP Server URL. Leave Additional settings empty.
  3. Press Next, approve access, and sign in with Todoist.
  4. Ask “what are my Todoist tasks today?” and choose Always allow.

For Gemini CLI, add this to ~/.gemini/settings.json, then run /mcp auth todoist:

{
  "mcpServers": {
    "todoist": { "httpUrl": "{{ORIGIN}}/mcp" }
  }
}
Cursor

Add this to ~/.cursor/mcp.json, then sign in with Todoist when Cursor asks:

{
  "mcpServers": {
    "todoist": { "url": "{{ORIGIN}}/mcp" }
  }
}
VS Code

Add this to .vscode/mcp.json, then sign in with Todoist when VS Code asks:

{
  "servers": {
    "todoist": { "type": "http", "url": "{{ORIGIN}}/mcp" }
  }
}
