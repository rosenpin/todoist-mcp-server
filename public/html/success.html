Todoist MCP

Todoist is connected

Add this server URL to your AI assistant to start using your tasks.

This URL gives full access to your Todoist account. Keep it private, like a password.

Add it to your client

Claude

In claude.ai or Claude Desktop, open Settings → Connectors → Add custom connector, name it “Todoist” and paste the URL.

For Claude Code, run:

claude mcp add --transport http todoist "{{MCP_URL}}"

Video walkthrough

ChatGPT

Enable Developer mode under Settings → Apps & Connectors → Advanced, then choose Create, paste the URL and set authentication to “No authentication”.

Gemini

Gemini uses Todoist sign-in instead of the URL above. Add this server and sign in when prompted:

{{ORIGIN}}/mcp

For Gemini CLI, add to ~/.gemini/settings.json:

{
  "mcpServers": {
    "todoist": { "httpUrl": "{{ORIGIN}}/mcp" }
  }
}
Cursor

Add to ~/.cursor/mcp.json:

{
  "mcpServers": {
    "todoist": { "url": "{{MCP_URL}}" }
  }
}
VS Code

Add to .vscode/mcp.json:

{
  "servers": {
    "todoist": { "type": "http", "url": "{{MCP_URL}}" }
  }
}
Other clients

Add the URL as a remote MCP server. It speaks Streamable HTTP and, for older clients, SSE. No extra authentication is needed.

Available tools

Tasks
get_tasks, create_task, update_task, complete_task, uncomplete_task
Projects
list_projects, create_project, update_project, delete_project
Sections
get_sections, create_section
Labels
get_labels, create_label
Comments
get_comments, create_comment

Disconnect

Deletes your stored Todoist token. This URL stops working immediately.
